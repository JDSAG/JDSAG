## Projetos em destaque

### MesaJá — Pedidos por QR Code para restaurantes

Sistema de pedidos digitais que permite ao cliente acessar o cardápio da mesa por QR Code e enviar pedidos à operação do restaurante. O projeto contempla sessões de mesa, gerenciamento de pedidos, fluxo de atendimento e acompanhamento pela equipe.

- **Contribuições técnicas:** integração frontend/backend, criação e consumo de endpoints, autenticação por sessão, controle de estados de pedidos e tratamento de erros de integração.
- **Tecnologias:** React, JavaScript, Vite, Python, FastAPI, SQLAlchemy, PostgreSQL, JWT, Render e Vercel.

### Med-Alert — Cartão de emergência digital

Aplicação associada a um cartão físico com NFC, pensada para facilitar o acesso a informações importantes em uma emergência, como alergias, tipo sanguíneo, laudos e contato de emergência, conforme as informações disponibilizadas pelo titular.

- **Contribuições técnicas:** desenvolvimento com JavaScript, organização de módulos de autenticação e dados, integração com banco relacional e disponibilização de uma página pública para consulta.
- **Tecnologias:** JavaScript, HTML, CSS, PostgreSQL, Node.js/Vercel Functions e Aiven.
- **Demonstração:** [cartaoemergencial.vercel.app](https://cartaoemergencial.vercel.app)

### Pipeline de ETL e integração de dados

Projeto de prática com extração, transformação e carregamento de dados entre serviços e banco relacional, aplicando limpeza, normalização e preparação dos dados antes da persistência.

- **Foco técnico:** tratamento de dados, expressões regulares, integração com banco de dados e automação de etapas de processamento.
- **Tecnologias:** Python, pandas, regex, SQLAlchemy, Supabase e MySQL.

### FinancePro — Aplicação desktop para controle financeiro

Aplicação desktop desenvolvida como projeto prático para trabalhar a organização de dados e a construção de uma interface de usuário em Python.

- **Foco técnico:** estruturação de funcionalidades e interface desktop.
- **Tecnologias:** Python e CustomTkinter.

### Sistema de agendamento médico

Projeto voltado ao gerenciamento de agendamentos e à prática de persistência de dados e autenticação.

- **Foco técnico:** operações CRUD, modelagem de dados e controle de acesso com token.
- **Tecnologias:** Python, SQLAlchemy, SQLite e JWT.

## Experiência prática

Minha experiência até aqui vem principalmente do desenvolvimento de projetos próprios e de estudo, nos quais tenho praticado diferentes etapas do ciclo de desenvolvimento:

- **Desenvolvimento full-stack:** construção de interfaces e integração com serviços de backend.
- **Desenvolvimento de APIs:** criação de rotas, validação de dados, autenticação e comunicação entre componentes.
- **Bancos de dados:** modelagem relacional, consultas SQL e integração de aplicações com PostgreSQL, MySQL e SQLite.
- **Deploy e configuração:** uso de variáveis de ambiente, configuração de CORS e publicação de aplicações em serviços de hospedagem.
- **Depuração:** análise de respostas HTTP, logs, erros de integração e comportamento da aplicação em produção.
- **Dados:** limpeza, transformação e movimentação de dados entre fontes e bancos relacionais.
